# Как запустить

Нужен Python 3.8+, сторонние пакеты не требуются.

```
python3 report.py --date 10.11.2026
```

- `--date` - дата отчёта, `ДД.ММ.ГГГГ` или `ГГГГ-ММ-ДД` (по умолчанию сегодня).
- `--data` - папка с `contracts.csv`, `works.csv`, `payments.csv` (по умолчанию `data`).

Файлы проекта: `report.py` - программа, `DECISIONS.md` - решения и допущения, `NOTE.md` - записка бухгалтеру.
Транскрипт для сдачи делается командой `/export` в Claude Code (см. ниже в сообщении).
